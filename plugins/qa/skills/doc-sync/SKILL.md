# SKILL: DOC_SYNC

Общая часть — здесь; транспорт, разметка, ловушки и скрипты — в `confluence/`.

| Адресат | Куда смотреть | Транспорт |
|---|---|---|
| **Confluence DC** (`confluence.example.com`) | `confluence/notes.md`, реестр `confluence/registry.json`, `confluence/upload.py`, `confluence/md2wiki.py` | REST по PAT, markdown → wiki-разметка |

## Цель и инварианты

**Источник истины — Obsidian-vault.** Confluence — выгрузка для команды, а не место правки: страница,
исправленная руками в интерфейсе, будет затёрта следующей выгрузкой.

1. **Один файл vault = одна страница.** Повторный запуск **обновляет** существующую страницу по
   `pageId` из реестра, а не создаёт новую.
2. **Никогда не создавать страницу для файла, у которого есть запись в реестре.** Создание допустимо
   только для файла без записи — и сразу после него запись добавляется в реестр.
3. **Перед любой записью свериться с реестром.** Реестр ведёт `upload.py`; руками его не правят.
4. **Переименование — это правка заголовка**, а не пересоздание страницы.
5. **`.md` создаются и правятся только в Obsidian** (правило vault'а); Confluence правится через
   `upload.py`. Реестр — служебный JSON скилла, не документация.

## Порядок работы

1. **Определить объём.** Пользователь назвал конкретные файлы — синхронизируем их;
   «обнови все доки» — идём по записям реестра нужного проекта.
2. **Прочитать реестр**, найти записи для целевых файлов.
3. **Прочитать источник из vault** (`mcp__obsidian__vault_read` либо Obsidian CLI).
4. **Преобразовать содержимое** — правила в `confluence/notes.md`: конвертация markdown → wiki
   лоссовая, callouts уходят в нативные панели, mermaid рендерится в SVG-вложение.
5. **Записать**: есть запись в реестре → обновление по `pageId`; нет → создание плюс новая
   запись в реестре.
6. **Отчёт**: что обновлено, что создано, что пропущено и почему.

**Сначала всегда сухой прогон** (`--dry`): выгрузка трогает страницы, которые читают коллеги.

## Общее для преобразования

- Frontmatter (`---…---`) — убрать.
- H1 статьи — убрать: у страницы собственный заголовок, иначе он задвоится.
- Wikilinks `[[…]]` — заменить читаемым текстом либо ссылкой на страницу, если цель уже в реестре.
- Экранирование `\|` в таблицах — снять, это специфика Obsidian.
- Эмбеды изображений на пути vault — убрать либо приложить вложением.

## Wiki-дисциплина

Выгружается **export-слой** (`Company/Projects/…`). Рабочий слой (`Company/_wiki/…`) наружу не идёт:
там планы, аудиты, карты и заметки, адресованные агенту, а не коллегам. Ссылки между деревьями
внутри export-документов не ставим — они утекут вместе со статьёй.

## Анти-паттерны

- ❌ Создать страницу, не проверив реестр → дубль статьи в Confluence.
- ❌ Править реестр руками: его ведёт `upload.py`.
- ❌ Править страницу в интерфейсе Confluence вместо источника в vault.
- ❌ Выгружать рабочий слой вики целиком «за компанию».
